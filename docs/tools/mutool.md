# mutool

## NAME
mutool - command-line tool with multiple sub-tools

## SYNOPSIS

> **mutool** [*command*] [*arguments* *...*]

## DESCRIPTION

Run mutool without any options to see a list of available commands.

Here are a few highlights:

[mutool draw](/tools/mutool-draw.md)
: This is the more customizable tool, but also has a more difficult set of
command line options. It is primarily used for rendering a document to
image files.

[mutool convert](/tools/mutool-convert.md)
: This tool is used for converting documents into other formats, and is
easier to use.

[mutool show](/tools/mutool-show.md)
: A tool for displaying the internal objects in a PDF file.

[mutool grep](/tools/mutool-grep.md)
: Search text content of documents.

[mutool extract](/tools/mutool-extract.md)
: Extract images and embedded font resources.

[mutool clean](/tools/mutool-clean.md)
: Rewrite PDF file. Used to fix broken files, or to make a PDF file human
editable.

[mutool create](/tools/mutool-create.md)
: Create a new PDF file from a text file with graphics commands.

[mutool merge](/tools/mutool-merge.md)
: Merge pages from multiple input files into a new PDF.

[mutool poster](/tools/mutool-poster.md)
: Divide pages of a PDF into pieces that can be printed and merged into a
large poster.

[mutool run](/tools/mutool-run.md)
: Do anything you can imagine!
