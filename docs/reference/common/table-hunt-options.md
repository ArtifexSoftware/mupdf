# Table Hunt Options

The options are specified using an <a href="option-strings.html">option string</a> of key-value pairs.

These are currently experimental and subject to change without notice.

**vertically-collapse-bordered-cells**
: If true, then the contents of any completely bordered cell will be considered
as appropriate for collapsing vertically. The default is false.
